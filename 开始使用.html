CHATGPT → PDF

对话成册

把网页聊天整理成可以保存、搜索和打印的文档。
适用于 Chrome / Edge，无需服务器或 API Key。

先看看示例效果 ↗完整说明

1.0.2 新增点击左侧消息定位。点击消息文字可滚动到正文并短暂高亮，复选框控制是否导出。已安装旧版时，请覆盖原扩展文件夹，在扩展管理页点击“重新加载”，确认版本为 1.0.2。关闭旧预览，从原聊天重新打开。

安装一次，以后直接使用

  1. 解压下载的 ZIP 文件，保留 chatgpt-to-pdf 文件夹。
  2. 在 Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。
  3. 开启开发者模式，点击加载已解压的扩展程序，选择包含 manifest.json 的文件夹。
  4. 点击浏览器工具栏的扩展按钮，把对话成册固定到工具栏。

导出一段聊天

  1. 在 ChatGPT 网页打开聊天，等待回答完成，并滚动加载需要保留的历史内容。
  2. 点击工具栏的对话成册图标。
  3. 在预览中修改标题、勾选消息、设置纸张与字号。
  4. 点击保存为 PDF，在浏览器打印窗口选择另存为 PDF，再保存文件。

建议关闭浏览器打印窗口的“页眉和页脚”。宽表格可切换横向纸张，最终分页以打印窗口为准。

导出前核对这两件事

消息是否完整：本版只读取当前页面已加载的当前聊天分支，不会自动遍历账号里的全部聊天。虚拟滚动可能使较早内容卸载，请核对第一条、最后一条和消息数量。

图片是否显示：未能嵌入的图片会显示文字提示。勾选“允许加载未嵌入的原图片”会尝试连接原图片网站；受登录或跨域限制时仍可能失败。
