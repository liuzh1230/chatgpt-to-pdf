# 对话成册 · ChatGPT 转 PDF

Chrome / Edge 本地扩展，支持导出当前 ChatGPT 聊天，以及粘贴分享链接导出。使用浏览器原生打印生成 PDF，无需服务器、账号密钥或付费接口。

当前版本：**v1.0.5（2026-10-07）**。[下载 v1.0.5 安装包](https://github.com/liuzh1230/chatgpt-to-pdf/raw/refs/tags/v1.0.5/dist/chatgpt-to-pdf-v1.0.5.zip)，或查看 [v1.0.5 源码](https://github.com/liuzh1230/chatgpt-to-pdf/tree/v1.0.5)。这是手动加载的本地扩展，尚未上架扩展商店。

## 安装或更新

1. 解压 `chatgpt-to-pdf-v1.0.5.zip`，保留其中的 `chatgpt-to-pdf` 文件夹。
2. 打开 `edge://extensions` 或 `chrome://extensions`，开启开发者模式。
3. 点击「加载已解压的扩展程序」，选择**直接包含 manifest.json 的 chatgpt-to-pdf 文件夹**。
4. 确认版本 **1.0.5**，将「对话成册」固定到工具栏。若同时安装了旧版，停用旧版，避免点错图标。

已有用户也可以将新版文件复制到浏览器原先加载的扩展文件夹，再在扩展管理页点击「重新加载」，沿用原扩展身份及排版偏好。关闭旧预览，刷新原聊天后再使用。仅解压到另一目录不会更新已安装的扩展。

## 新增：导出分享链接

1. **右键工具栏的「对话成册」图标 → 选项**。也可以在任一 PDF 预览页点击右上角「分享链接导出」。
2. 粘贴完整链接，例如 `https://chatgpt.com/share/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`。
3. 点击「读取分享链接」。首次使用时，允许浏览器请求的 `chatgpt.com` 网站访问权限。
4. 扩展打开分享页并等待正文稳定，然后自动打开原有 PDF 预览。
5. 核对消息数量、首尾内容及读取提示；选择消息、纸张、方向和字号。
6. 点击「保存为 PDF」，在浏览器打印窗口选择「另存为 PDF」并保存。

旧域名 `https://chat.openai.com/share/…` 会转为 chatgpt.com；链接的追踪参数和片段会移除。不接受私人 `/c/` 链接、其他网站或不完整的分享 ID。

等待期间请保留分享页。网页加载及正文等待分别最多约 45 秒，随后图片读取可能还需要数秒。若链接失效、需要登录或网页验证，请在已打开的分享页处理后重试，也可以直接在该页点击原来的扩展图标导出。扩展不会绕过登录或验证码，也不会关闭原分享页。

## 原有功能：导出当前聊天

工具栏**单击行为保持不变**：打开想导出的 ChatGPT 聊天 → 等待回答结束、滚动加载历史 → 点击「对话成册」图标 → 在预览中筛选并保存 PDF。

标题修改、逐条勾选、按说话者筛选、点击消息定位、A4 / Letter、纵向 / 横向、字号、图片与来源信息开关全部保留。正文提取、净化和预览脚本与 v1.0.4 完全一致；新增公式适配仅在分享链接入口启用。

建议在打印窗口关闭「页眉和页脚」、开启「背景图形」。最终分页以打印窗口为准；仍需手动选择保存位置。

## 内容与边界

- 支持中文、英文、标题、列表、引用、代码、表格、可读取的图片和 MathML / 常见 KaTeX 公式。
- 分享页只提供 `data-math-source` 公式源码时，使用本地 KaTeX 转为 MathML。无法转换的公式完整保留源码并显示提示，不擅自修正公式含义。
- **只读取分享页当前已加载的正文。**不枚举全部聊天、不调用聊天记录后端接口，也不保证长对话、虚拟滚动或未公开内容完整。
- 页面有空对话区块时会提示，请核对原分享页。未分享的正文、附件文件本体、交互画布、音视频及嵌入应用不在导出范围。
- 优先嵌入可读取的图片像素；受登录、跨域或大小限制的图片保留提示。预览中的「允许加载未嵌入的原图片」会连接图片原网站。
- 临时存储容量约 10 MB，多图聊天过大时会提示关闭其他预览；图片快照最长边最多 1800 像素。
- 网页结构可能变化。单个分享链接验证成功不代表所有分享页面都已适配。

## 隐私与权限

没有第三方上传服务器、统计分析或远程脚本。打开分享页会正常连接 ChatGPT；只有主动允许加载原图时，预览才连接相应图片网站。

- `activeTab`、`scripting`、`storage`：原有当前页面导出、临时存储和排版偏好。
- **可选** `https://chatgpt.com/*`：点击「读取分享链接」时申请，用于读取新打开的分享标签页。浏览器权限覆盖整个网站，代码只在主动发起导出时执行读取。
- 分享入口下方提供「撤销分享页访问权限」。拒绝或撤销不影响原来的工具栏当前聊天导出。
- 聊天副本仅存于 `storage.session`，关闭对应预览后删除；浏览器重启清除，超过六小时的旧副本在下次导出时清理。
- `storage.local` 只存纸张、字号等偏好，不保存正文、标题或分享地址。分享输入也不会存入长期存储。
- 不读取 Cookie、账号令牌或密码。

## 文件与验证

- `background.js` / `capture.js` / `sanitize.js`：原有导出核心。
- `preview.html` / `preview.js` / `styles.css`：筛选、排版、定位与打印。
- `share.html` / `share.js` / `share.css`：新增分享入口。
- `share-url.js` / `share-ready.js` / `share-background.js`：链接校验、加载等待与调度。
- `share-math.js` / `vendor/`：分享页公式转换及第三方许可证。
- `TESTING.md`：本次检查、真实页面结果与验证边界。

不安装时可打开 `preview.html?demo=1` 查看虚构示例；真实导出必须安装扩展。安装包带齐文件，无需额外构建或运行时下载依赖。

实现参考：[Chrome 可选权限](https://developer.chrome.com/docs/extensions/reference/api/permissions)、[扩展选项页](https://developer.chrome.com/docs/extensions/develop/ui/options-page)、[KaTeX MathML 输出](https://katex.org/docs/options)。

本项目为独立工具，与 OpenAI 无隶属关系。
