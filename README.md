# 对话成册 · ChatGPT 转 PDF

Chrome / Edge 本地扩展，直接将 ChatGPT **当前页面已经加载的聊天**整理成 PDF。无需服务器、账号密钥或付费接口。使用浏览器原生打印生成可搜索、可复制文字的 PDF。

**当前版本：1.0.2** · [下载可安装扩展 ZIP](https://github.com/liuzh1230/chatgpt-to-pdf/raw/refs/heads/main/dist/chatgpt-to-pdf-v1.0.2.zip) · [更新记录](CHANGELOG.md) · [测试范围](TESTING.md)

直接下载上面的安装包并解压即可。也可以使用 GitHub 的 Code → Download ZIP 下载整个仓库，再加载根目录中的 `manifest.json`；`dist/` 内附有独立安装包。扩展无需编译。

## 安装（约 1 分钟）

1. 解压下载的扩展 ZIP，保留解压后的文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择含有 `manifest.json` 的 `chatgpt-to-pdf` 文件夹。**不要选择 ZIP 文件或它的上级文件夹。**
5. 点击浏览器工具栏的扩展按钮，将「对话成册」固定在工具栏上。

这是提供源码的本地开发版，没有上架扩展商店。浏览器由学校或公司统一管理时，管理员可能禁止加载本地扩展。

## 使用

1. 打开 `https://chatgpt.com`，进入想导出的聊天。
2. 等待回答生成完毕。长聊天请先向上滚动，确认历史消息已加载；展开需要导出的折叠内容。
3. 点击工具栏中的「对话成册」图标，扩展会打开独立预览页。
4. 修改文档标题，选择全部消息、仅 ChatGPT 或仅我的提问；也可以逐条取消勾选。点击左侧消息文字，可定位到对应正文。
5. 根据需要选择 A4 / Letter、纵向 / 横向、字号，核对开头、结尾、表格与图片。
6. 点击「保存为 PDF」，在浏览器打印窗口的目标打印机中选择「另存为 PDF」，再点击保存。

建议关闭打印窗口中的「页眉和页脚」，开启「背景图形」以保留配色；通常使用默认缩放即可。实际分页以打印窗口为准。扩展无法绕过浏览器的保存窗口或替你选择文件路径。

## 支持内容

- 中文、英文、标题、列表、引用、普通链接。
- 代码块、自动换行、跨页长回答。
- 表格及分页时重复的表头；宽表格建议使用横向纸张。
- 网页中的原生 MathML / 常见 KaTeX 公式。没有 MathML 的部分公式可能回退为文本。
- 浏览器允许读取的图片会作为本地快照保留。受跨域、登录或大小限制的图片显示提示，需要勾选「允许加载未嵌入的原图片」后尝试从原网站读取。
- PDF 正文使用文字排版，不把整段对话拼成长截图。图片本身仍为图片，文字可选择性由浏览器和字体决定。

## 范围与限制

**不会自动遍历账号里的全部聊天，也不会自动加载无限长历史。** 只读取当前页面 DOM 中已加载的当前对话分支。页面已经卸载、未加载或隐藏的消息不会被读取。对虚拟滚动页面，即使向上滚动过，也可能仍缺少已卸载的消息，务必核对首尾与数量。

- 不枚举或调用聊天记录后端接口，不读取 Cookie、令牌或账号凭据；仅在必要时请求页面图片已经使用的原地址，由浏览器按正常同源规则携带会话。
- 不导出其他分支、附件文件本体、隐藏思考内容、音视频、交互画布或嵌入应用。普通附件名称可能以文字保留。
- ChatGPT 网页结构变化后，正文识别规则可能需要维护。空内容会报错；无法自动证明读取的聊天是否完整。
- 读取阶段优先复制页面中已加载的图片像素；必要时从原聊天页面请求图片已有的地址。独立预览页不会自动加载尚未嵌入的远程图片，只有勾选加载原图片后才连接原图片网站；仍可能受登录或跨域限制，无法加载时保留文字标记。
- 单张/总图片大小有限制，快照最长边最多 1800 像素。预览临时存储与其他预览共用浏览器约 10 MB 的 session 容量，过大时会明确提示。关闭不用的预览后可重试。
- 超宽公式、非常复杂的表格或单元格仍可能受浏览器打印能力限制，请检查最终预览。

## 隐私与权限

没有服务器、统计分析、远程脚本或上传接口。

- `activeTab`：仅在你点击扩展后，临时读取当前标签页。
- `scripting`：读取 ChatGPT 页面中的已显示聊天内容。
- `storage`：聊天副本暂存在浏览器内存中的 `storage.session`；关闭预览标签页时删除，浏览器重启也会清除。超过 6 小时的旧副本在下次打开扩展时清理。
- `storage.local` 只保存纸张、字号、消息范围等偏好，不保存聊天正文、标题或来源链接。
- 没有申请常驻的全站访问权限。

关闭预览后的数据清除不影响你自行保存到磁盘的 PDF。导出时可取消「保留来源与导出时间」，避免把聊天地址写进 PDF 正文；浏览器自己的页眉页脚请在打印窗口单独关闭。

## 不安装也能查看界面

双击 `preview.html` 并在地址末尾加上 `?demo=1`，可查看随包附带的虚构示例。真实聊天读取仍需安装扩展。没有打包步骤，也没有运行时依赖。

## 文件说明

- `manifest.json`：Chrome Manifest V3 扩展配置。
- `background.js`：响应工具栏点击、临时存储和清理。
- `capture.js`：网页正文、代码、公式和图片读取。
- `sanitize.js`：标签、属性和 URL 白名单净化。
- `preview.html` / `preview.js` / `styles.css`：筛选、排版和打印。
- `demo.js`：虚构示例对话。
